# SIS — ริก Blender และ VRM พร้อมฟิสิกส์

## ไฟล์ใช้งาน

- **SIS_Rigged.blend**: ไฟล์หลักสำหรับจัดท่าและทำแอนิเมชัน พร้อมแผงควบคุม SIS Rig
- **SIS_Rigged_Physics.vrm**: VRM 1.0 สำหรับเกม มี Humanoid, สีหน้า, น้ำหนักกระดูก และ Spring Bone
- **SIS_Physics_Demo.blend**: เดโม 3 วินาที กด Space เล่นได้ ฟิสิกส์จากการจำลองถูกบันทึกเป็นคีย์เฟรมแล้ว
- **SIS_Face_Controls.png / SIS_Physics_Pose.png**: ภาพตรวจสีหน้าและการเคลื่อนไหว

ต้นฉบับ `E:/NONAMEGAME MODEL/SIS.vrm` และไฟล์ในฉาก Unity เดิมไม่ได้ถูกเขียนทับ

## ใช้งานใน Blender

ติดตั้งและเปิดใช้ **VRM format 4.7.1** และ **SIS Rig Controls** ใน Blender 5.2 ของเครื่องนี้แล้ว

1. เปิด `SIS_Rigged.blend` แล้วเลือก Armature ชื่อ `SIS_Rig`
2. ในหน้าต่าง 3D กด **N → SIS Rig**
3. เข้า **Pose Mode** เพื่อขยับตัวจับ `CTRL_…` ตัวจับเล็กตามนิ้วใช้หมุนนิ้วได้
4. แขน/ขาเริ่มแบบ FK หากต้องการลากมือหรือเท้า ให้ปรับ `IK Hand L/R` หรือ `IK Foot L/R` เป็น **1** แล้วขยับกระดูก `IK_Hand_…` หรือ `IK_Foot_…` ใช้ `POLE_…` กำหนดทิศศอก/เข่า
5. หน้า: ใช้สไลเดอร์ Blink, Eye Wide, Eye Yaw/Pitch, Brow และ Mouth ปุ่ม **Reset face** คืนหน้าเป็นกลาง
6. ผมและเสื้อผ้า: เปิด **Enable animation** แล้วเล่น Timeline หรือขยับตัวละคร ขยาย **VRM → Spring Bone** เพื่อปรับ stiffness, drag, gravity และ collider รายชุด
7. ถ้าจำลองค้างจากการเลื่อนเวลาข้ามเฟรม ให้หยุดที่เฟรมต้นแล้วกด **Reset spring simulation** ก่อนเล่นใหม่

ในเดโมปิด Live Spring ไว้ เพราะบันทึกฟิสิกส์ลงคีย์เฟรมแล้ว ไม่ควรเปิดซ้ำขณะเล่นเดโม ใช้ไฟล์หลักสำหรับแก้ไขและทดลองฟิสิกส์สด

การเปลี่ยนค่า FK/IK เป็นการเปลี่ยนโหมด ไม่มีระบบ snap รักษาท่าอัตโนมัติ ให้จัดตำแหน่งเป้าหมายก่อนเปลี่ยนโหมดระหว่างแอนิเมชัน

## สิ่งที่ทำ

- เก็บ Humanoid เดิมครบ **54 ตำแหน่ง** รวมกระดูกตาและนิ้ว และรักษาน้ำหนักตัว/ผม/เสื้อผ้าเดิม
- เพิ่มตัวจับ FK ทั้งตัว พร้อม IK มือ–เท้าและตัวกำหนดทิศศอก–เข่า
- เก็บ morph เดิม **57 แบบ** เพิ่ม **14 morph** แยกซ้าย–ขวาจากรูปร่างเดิม: คิ้วยก/กด/เศร้า/ยิ้ม, มุมปากยิ้ม/เศร้า และตาเบิกกว้าง
- แผงหน้ามี **21 สไลเดอร์ morph** และการมองซ้าย–ขวา/ขึ้น–ลง
- ปรับฟิสิกส์ **37 ชุด** ได้แก่ผม 19 ชุด กระโปรง 6 ชุด ชายเสื้อ 6 ชุด แขนเสื้อ 4 ชุด และชุดเดิมของลำตัว 2 ชุด
- เพิ่มการชนแขนเสื้อ รวม collider เป็น **32 ตัว**
- แพ็กภาพและพื้นผิว **22 ภาพ** ในไฟล์ Blender

ฟิสิกส์เสื้อผ้าเป็น **VRM Spring Bone** จึงแกว่งตามกระดูกและทำงานกับเกมที่รองรับ VRM 1.0 ไม่ใช่การจำลองผ้าเต็มแผ่นที่สร้างรอยย่นอัตโนมัติ รอยพับและน้ำหนักยังอิงโมเดลต้นฉบับ

VRM มีริก deform และ expression มาตรฐาน ส่วนตัวจับ FK/IK และแผง SIS Rig ใช้ใน Blender เท่านั้น นำเข้า VRM ใหม่เป็นโมเดลแยกก่อนเปลี่ยนตัวละครในฉากจริง

## Expression เพิ่มใน VRM

`Brow_Up_L/R`, `Brow_Down_L/R`, `Brow_Sad_L/R`, `Brow_Happy_L/R`, `Mouth_Smile_L/R`, `Mouth_Frown_L/R`, `Eye_Wide_L/R`

blinkLeft/blinkRight และ aa/ih/ou/ee/oh เดิมยังอยู่ครบ การติดตามหน้าจากกล้องต้องเชื่อมชื่อ expression เหล่านี้ในโปรแกรมปลายทางเอง ยังไม่ได้แก้ระบบเว็บแคมใน Unity

## ตรวจแล้ว

- เปิดไฟล์ Blender ที่บันทึกกลับมา แล้วทดสอบสไลเดอร์หน้าทุกตัวและกระดูกตา
- ทดสอบ IK ทั้งสี่แขนขา รวมทิศ pole ระยะคลาดจากเป้าหมายต่ำกว่า 0.02 มม. ในท่าทดสอบ
- จำลอง 90 เฟรม (30 fps, สองขั้นจำลองต่อเฟรม): ทุกกลุ่มผม/เสื้อผ้ามีการตอบสนองและไม่มีค่าที่ไม่เป็นตัวเลข
- ตรวจโครงสร้าง VRM: Humanoid, expression, spring และดัชนี collider ครบ
- การเคลื่อนไหวแรงหรือท่าที่ต่างจากเดโมมากอาจต้องปรับน้ำหนัก/ขนาด collider เพิ่ม ยังไม่ได้รับรองทุกท่าหรือทดสอบ VRM ใหม่นี้ใน Unity

รายละเอียดตัวเลขอยู่ใน `validation.json` และค่าริกหน้าอยู่ใน `rig_channels.json`
