# โครงบ้านสองชั้นสำหรับเกม

เปิด `House2163_Shell.blend` ใน Blender โมเดลใช้หน่วยเมตร มีเฉพาะโครงอาคาร ไม่มีเฟอร์นิเจอร์ สุขภัณฑ์ รถ หรือต้นไม้ ภาพแปลนต้นฉบับถูกแพ็กไว้ในไฟล์ Blender สำหรับใช้อ้างอิง

Collections:
- `00_Site`: พื้นจอดรถและทางเข้า
- `01_GroundFloor`: พื้น ผนัง ห้องนอน ห้องน้ำ ครัว ซักล้าง และระเบียงชั้นล่าง
- `02_Staircase`: บันไดรูปตัวยูและราวกันตก
- `03_UpperFloor`: ห้องนอนด้านหลังสองห้อง ห้องนอนใหญ่ด้านหน้า ห้องน้ำ พื้นที่ออนเซ็นเปล่า โถง และระเบียง
- `04_Roof`: หลังคาแบน ถอดซ่อนทั้ง Collection เพื่อดูชั้นบน ซ่อนชั้นบนเพิ่มเพื่อดูชั้นล่าง

เป็นการประมาณสัดส่วนจากภาพ ไม่ใช่แบบก่อสร้างที่วัดได้แม่นยำทุกจุด ตัวอาคารหลักกว้างประมาณ 7.6 เมตร ลึก 12 เมตร สูงระหว่างพื้นชั้นละ 3.2 เมตร ผนังนอก 20 ซม. ผนังใน 15 ซม. ภาพไม่มีรูปด้าน จึงสมมติความสูง ช่องหน้าต่าง และหลังคาแบน ประตูเป็นช่องเปิด ไม่มีบานประตูหรือกระจก

ไฟล์เพิ่มเติมสำหรับ Unity อยู่ใน `Assets/House2163`: FBX และ Prefab พร้อมวัสดุ URP และ BoxCollider แยกชิ้น ยังไม่ได้ทดสอบการเดินใน Unity โมเดลมี UV พื้นฐานจาก primitive cube; ยังไม่ได้ทำ UV atlas หรือ lightmap UV แบบรวม
