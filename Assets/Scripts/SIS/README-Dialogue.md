# Min / Miu world dialogue

ระบบบทพูดลอยในโลกเกมที่ได้แรงบันดาลใจจาก MiSide ไม่ได้ใช้โค้ดหรือทรัพยากรของเกมนั้น

## ทดลองใน DemoHouse

1. เปิด Bootstrap แล้วกด Play ระบบจะพาเข้า DemoHouse อัตโนมัติ
2. มองมินหรือมิอุในระยะโต้ตอบ กด E เพื่อเริ่มพูด ระหว่างฟังหมุนกล้องได้ แต่เดินไม่ได้
3. กด E ระหว่างข้อความกำลังพิมพ์เพื่อแสดงทั้งประโยค กด E เมื่อครบแล้วเพื่อเปิดเมนู
4. เลือกคุยทั่วไป ถามเรื่องอดีต หรือถามเรื่องมิอุด้วยเมาส์ ระหว่างเลือกเมนูกล้องจะหยุดหมุน
5. คำถามบางข้อเปิดได้เมื่อผู้เล่นมีความรู้จากลูปก่อนหน้า กด Esc เพื่อจบบทสนทนาได้ทุกช่วง

ใช้ Canvas เดิมสำหรับเมนูและคำแนะนำ ส่วนบทพูดเป็น TextMeshPro แบบ 3D ที่สร้างและลบอัตโนมัติ ไม่ต้องสร้าง Canvas เพิ่ม

## ตั้งค่า

เลือก Canvas เดิมที่มี `SisterDialogueBuilder` (ชื่อคลาสเดิมถูกเก็บไว้เพื่อรักษาการเชื่อมโยงในฉาก):

- Thai Font: ใช้ Sarabun SDF ที่มีอยู่
- Speech Offset: ตำแหน่งบทพูดเทียบกับจุดยืนและทิศหันของน้อง หน่วยเป็นเมตร (ไม่คูณสเกลโมเดล)
- Speech Width / Speech Font Size: ความกว้างและขนาดข้อความ
- Speech Bob: ระยะลอยขึ้นลง ตั้ง 0 เพื่อปิด
- Speech Color: สีบทพูด มีขอบขาวแยกวัสดุจากฟอนต์เดิม

ใน `SisterDialogueUI` ปรับ Characters Per Second และ General Lines ได้ตามเดิม
กล้องต้องเป็นลูกของ GameObject ที่ติด `PlayerLook` ระบบติดตามและการมองหัวใช้คอมโพเนนต์เดิม
ระบบมองหัวเดิมยังต้องมี Animator Humanoid และเปิด IK Pass ตามการตั้งค่าเดิม

ข้อความอยู่ในโลกเกม จึงหลุดจอเมื่อหันหนีและถูกฉากบังได้ ไม่ใช่ซับที่ติดหน้าจอ
ยังไม่ได้เพิ่มเสียงพูด, lip sync หรือคลิปท่าพูดเฉพาะบท

## ตรวจอัตโนมัติ

`Assets/Editor/ProjectValidation.cs` ตรวจ Build Settings ระบบหลัก ตัวละคร Min/Miu, MeshCollider และ Missing Script
ชุดทดสอบใน `Assets/Tests/EditMode` ตรวจความรู้ข้ามลูป จำนวนครั้งย้อนเวลา และข้อมูลเซฟถาวร
ควรตรวจขนาดข้อความ ตำแหน่ง การมองหัว และการใช้เมาส์จริงใน Game view เมื่อปรับงานภาพหรือ UI
